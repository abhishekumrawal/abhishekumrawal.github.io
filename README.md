# Abhishek Umrawal Website (Canonical HTML Version)

The `.html` files in this folder are now the canonical editable website. No Quarto build is required.

- `research.html` — Research
- `publications.html` — Publications and manuscripts

- `service.html` — Service

- `grants.html` — Grants

## How to maintain the site
For routine content changes, open the relevant `.html` file in a text editor, edit the content, save, and refresh the browser. The current HTML pages are self-contained and include the working visual styling and behavior used by the polished site.

`styles.css` and `site.js` are retained as shared design/behavior source references for future coordinated changes. For simple content updates, you do not need to edit them.

## Preview
Open `index.html` directly in a browser. No rendering or compilation command is needed.

## Binary assets to keep beside these files
Copy your existing versions into this folder as applicable:
- `photo.jpg`
- `cv.pdf`
- `research-statement.pdf`
- `teaching-statement.pdf`

## Publishing
Upload the page files and binary assets to the same directory on your web host. Keep filenames unchanged so the existing relative navigation continues to work.


### Editing format

All HTML pages are expanded and indented for direct editing. There is no build or compile step: edit, save, and refresh the browser.
